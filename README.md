# Amazing Zone

Amazing Zone is a full-stack e-commerce web project built with a static frontend and a Node.js backend connected to a cloud MySQL database.

## Features

- Product listing
- Product details
- Cart with quantity management
- User signup
- User login
- User profile update
- Order placement
- Invoice display after checkout
- Product images served from backend
- Cloud database connection with Railway
- Backend deployed online

## Tech Stack

### Frontend
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Vue.js 2

### Backend
- Node.js
- Express.js
- MySQL2
- CORS

### Database
- MySQL
- Railway cloud database

### Deployment
- Backend hosted online
- Database hosted on Railway
